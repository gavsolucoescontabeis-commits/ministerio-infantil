# Aviso jurídico — Ministério Infantil — 4ª IEQ Curitiba

## Finalidade da publicação

Este repositório é mantido publicamente por necessidade técnica de publicação e funcionamento do aplicativo. A exposição pública do código **não transforma o projeto em software livre ou de código aberto** e não concede autorização para terceiros utilizarem o código.

## Proteção do projeto

O histórico de commits, versões, datas e arquivos deste repositório documenta a evolução do software e ajuda a preservar evidências técnicas de autoria, desenvolvimento e anterioridade.

Todos os direitos sobre o código próprio do projeto ficam reservados, observadas as regras legais aplicáveis e eventuais direitos de terceiros sobre bibliotecas, serviços ou componentes externos.

## Uso não autorizado

É vedado o uso não autorizado do código-fonte, estrutura, regras de negócio, interface própria ou materiais do projeto para reprodução, redistribuição, comercialização ou criação de produto derivado.

## Registro formal

Para reforço de prova de autoria/titularidade, recomenda-se o registro da versão consolidada do software perante o INPI, com preservação do arquivo-fonte correspondente ao hash apresentado no registro.

## Titularidade formal

A definição jurídica final de titularidade deve ser documentada em instrumento próprio, especialmente se houver relação entre autor/desenvolvedor, igreja, ministério, empresa ou outro interessado.
